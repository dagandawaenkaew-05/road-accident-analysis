Road Accident Analysis with Power BI

Data Analysis | Python | Power BI

This team project analyzes road accident data to explore accident frequency, fatalities, injuries, and vehicle involvement across different provinces in Thailand.

Objectives
- Clean and prepare accident data using Python.
- Analyze accidents by province, suspected cause, and vehicle type.
- Create Power BI dashboards to visualize accident statistics and patterns.
Tools & Technologies
- Python (Pandas)
- Microsoft Power BI
